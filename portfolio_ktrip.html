03 · Technical Challenges

기술 챌린지 &
해결 전략 Technical Challenges &
Solution Strategy

2가지 핵심 기술 문제를 직접 정의하고, 좌표 기반 알고리즘과 JSON 구조화로 해결하여 OCR 인식률과 RAG 추천 정확도를 동시에 끌어올렸습니다. Directly defined and solved two core technical problems using coordinate-based algorithms and JSON structuring — simultaneously improving OCR recognition and RAG recommendation accuracy.

CHALLENGE 01

OCR 자간 인식 문제OCR Character Spacing Issue

메뉴판 디자인 특성상 OCR이 "우 동", "김 치"처럼 단어를 분리 인식하여 번역 품질과 메뉴 인식 정확도가 저하되었습니다. Due to menu design characteristics, OCR split words like "우 동" and "김 치" into separate tokens, degrading translation quality and menu recognition accuracy.

해결 전략Solution Strategy

텍스트의 Y좌표 근접도를 활용해 같은 행의 글자를 병합(Y좌표 근접도 병합). 공간 좌표 정보를 LLM 프롬프트에 주입하여 의미 단위로 재구성했습니다. Used Y-coordinate proximity to merge characters in the same row. Injected spatial coordinate data into the LLM prompt to reconstruct text into meaningful units.

의미 단위 재구성으로 인식률 개선Recognition improved via semantic unit reconstruction
CHALLENGE 02

RAG 컨텍스트 구조화RAG Context Structuring

초기에 단순 텍스트로 장소 정보를 전달했더니 LLM이 위치 정보나 콘텐츠 연관성을 정확히 파악하지 못해 추천 정확도가 하락했습니다. Initially passing location info as plain text caused the LLM to misidentify location data and content relevance, lowering recommendation accuracy.

해결 전략Solution Strategy

장소명·관련 콘텐츠·좌표·특징을 Key-Value 기반의 구조화된 JSON 컨텍스트로 변환하여 LLM이 정확한 정보 기반으로 동선을 설계하도록 개선했습니다. Converted place names, related content, coordinates, and features into structured Key-Value JSON context — enabling the LLM to design accurate, information-grounded itineraries.

LLM 정보 연관성 파악 능력 극대화Maximized LLM information relevance comprehension

I conceived KTrip to solve the friction faced by foreign tourists who love K-content. Rather than a simple translation app, I designed an AI travel guide that understands content preferences and dismantles language barriers through technology. Resolving OCR spacing issues with coordinate algorithms and improving RAG context through JSON structuring taught me firsthand how planning and engineering intersect.
